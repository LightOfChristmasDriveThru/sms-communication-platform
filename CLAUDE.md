# AI Employee Workspace

## Product

**Name**: Missed Lead Responder  
**Buyer**: Homecare owner/operators  
**Pain**: Inbound leads go cold when the team replies too late  
**Promise**: Respond to every missed lead before they book somewhere else

## How it works

1. Lead comes in via phone, email, or web form
2. If nobody answers within N minutes, system suggests a reply template
3. Team can use the suggestion or customize
4. Send + log the response in context

## This week's goal

**Ship a landing page + demo flow to send via Loom to 10 homecare owners.**

The landing page should convince an owner in 5 seconds that this solves their missed-lead problem.  
The demo should show: lead intake → suggested reply → follow-up.

## Quality bar

- **5-second clarity**: One look at the landing page, anyone knows what this does
- **Mobile-first**: Demo works on phone + desktop
- **Customer language**: Use the words homecare owners use (not "async", not "AI")
- **Specific over clever**: A homecare owner cares about booked consults, not features
